# 什么是编程？

编程可以理解为：把想解决的问题拆成一组足够清楚的步骤，再用计算机能够理解的语言把这些步骤写下来。

比如，给朋友写一份“煮面条”的说明，需要说清楚准备什么、先做什么、什么时候结束。计算机执行程序时也类似，只是它不会根据常识补全模糊的步骤，所以我们需要把条件、顺序和重复动作写得更准确。

## 程序由什么组成？

一个最简单的程序通常包含三类信息：

- **数据**：程序要处理的内容，例如姓名、年龄、商品价格。
- **规则**：程序应该如何处理数据，例如计算总价、判断是否通过。
- **输出**：程序处理后给用户看到的结果，例如一段文字、一个页面或一张图片。

下面的 JavaScript 程序保存了一个名字，并把问候语输出到控制台：

```js
const name = '小林'
console.log('你好，' + name + '！')
```

运行后，控制台会显示“你好，小林！”。name 是变量，变量可以看作一个有名字的盒子；console.log 是一个输出信息的函数。

## 程序是怎样做决定的？

程序不会只执行一条直线上的指令。我们还可以让它根据条件选择不同的路径：

```js
const score = 82

if (score >= 60) {
  console.log('通过')
} else {
  console.log('继续练习')
}
```

这里的 if 会先判断条件。分数大于等于 60 时输出“通过”，否则输出“继续练习”。这就是程序中的分支。

当一件事需要重复执行时，可以使用循环：

```js
for (let count = 1; count <= 3; count += 1) {
  console.log('第 ' + count + ' 次练习')
}
```

循环让我们不用复制三遍相同的代码。学习编程时，顺序、条件、循环和函数是非常重要的基础概念。

## 编程语言有什么区别？

Python、JavaScript、Java、Go 等都是编程语言。它们的语法、适用场景和生态不同，但背后的核心思想相通：

1. 接收或准备数据。
2. 按规则处理数据。
3. 产生结果。

Python 适合入门和数据处理，JavaScript 主要运行在浏览器中，也可以用于服务器开发；Java 和 Go 经常用于大型服务。没有一种语言适合所有问题，初学者应该先选一门语言持续练习，而不是同时学习很多门语言。

## 初学者如何开始？

建议按照下面的顺序练习：

1. 先学变量、类型、条件、循环和函数。
2. 用小程序解决具体问题，例如计算 BMI、生成乘法表或统计单词数量。
3. 练习阅读错误信息，学会根据报错定位代码。
4. 使用 Git 保存每次练习的变化。
5. 每学一个概念，就写一个能运行的例子。

编程不是背诵语法，而是持续把大问题拆成小问题。只要能让程序运行起来，再逐步改进它，你就已经在进行真正的编程了。
